# Platform layer

SDL3 windows/input, SDL_GPU (Metal on macOS, Vulkan on Linux), files, sockets, TLS (OpenSSL 3), pseudo-terminals: `src/VM-Platform`, in Lowtalk (docs/lowtalk.md), translated with the core into `vm/gen`. No policy, no rendering logic. `PlatformPrimitives` lists every primitive (400–699) with its arguments; the `pf_*` functions of the other modules (`PlatformWindows`, `PlatformGPU`, `PlatformEvents`, `PlatformFiles`, `PlatformSockets`, `PlatformTLS`, `PlatformPtys`, `PlatformVsync`, `PlatformNic`, `PlatformMachine`, `PlatformRaster`, `PlatformCommon`) are its C API, `SDLPlatform` implements the core's `PlatformInterface`, and `PlatformHost` holds what differs between operating systems (`DarwinPlatformHost`, `LinuxPlatformHost`: the refresh thread behind `vsyncSemaphore:`, the environment, socket setup, which keys are cmd and alt, the shader formats and compiling GLSL). Tests: `make -C vm/platform test` (`tests/gpu_test.c` against the generated internals, without the VM), `make -C vm/platform st-test` (Smalltalk through the real VM).

**Conventions.** Arguments are positional and the receiver is ignored. Handles are SmallIntegers. Byte buffers are ByteArray/ByteString (Bitmap where noted). Strings are UTF-8 with surrogateescape (docs/implementation.md, Primitive interface); a String argument holding U+0000 fails. `start` is 1-based. Pairs come back as Arrays (`{w. h}`). A primitive fails on bad arguments or OS/GPU errors, and `platformLastError` then returns the message (shader compile errors included: Metal's log, or shaderc's).

**Primitives.**
- Window: `windowOpen` (w h title flags: 1 hidden, 2 resizable, 4 highDensity), `windowClose`, `windowSize` (points), `windowPixelSize`, `windowDisplayScale`, `windowRefreshRate`, `windowSetTitle`, `windowSetSize` (win w h, points; a fixed-size window stays fixed at the new size), `windowSetTextInputArea` (win x y w h cursor, points: where text is typed, so the input method's candidates appear there; cursor is the caret's x within the rectangle), `windowShow`, `windowHide`, `setCursor` (0 arrow, 1 ibeam, 2 hand, 3 ew, 4 ns, 5 nwse, 6 nesw, 7 move, 8 wait, 9 crosshair, 10 notAllowed), `clipboardGet`, `clipboardSet`.
- Input: `nextEvent:` (8-slot Array; returns it filled, or nil), `injectEvent:` (same format, same queue), `inputSemaphore:`, `vsyncSemaphore:`, `droppedEvents` (events dropped since startup because the queue was full; `Smalltalk vm droppedEvents`). The queue holds at most 4096 events (`PF_EVENT_QUEUE_MAX`); further OS or injected events are dropped (injecting still succeeds).
- GPU: `gpuCreateDevice`, `gpuShaderLanguage` (`'msl'` or `'glsl'`: what `gpuCreateShader` takes on the device), `gpuClaimWindow`, `gpuSwapchainFormat`, `gpuCompileShader` (GLSL source, stage → the SPIR-V ByteArray it compiles to; fails where GLSL is not compiled, macOS), `gpuCreateShader` (source in the device's language, or a ByteArray of SPIR-V for a device that takes it) / `Pipeline` / `Texture` / `Sampler` / `Buffer`, `gpuRelease`, `gpuUploadBuffer` / `Texture`, `gpuAcquireCommandBuffer`, `gpuAcquireSwapchain` (`{tex. w. h}`, or nil when hidden/minimized or too many frames are in flight), `gpuBeginPass` (clear `{r. g. b. a}`, or nil to load) → pass, `gpuSetViewport`, `gpuSetScissor`, `gpuBindPipeline`, `gpuBindVertexBuffer`, `gpuBindTexture`, `gpuPushUniforms`, `gpuDraw`, `gpuEndPass`, `gpuBlit`, `gpuSubmit` (→ fence or nil), `gpuWaitFence`, `gpuFenceDone`, `gpuDownload` (synchronous, into a caller buffer; RGBA8, R8 = 1 byte), `gpuTextureSize`, `gpuWaitIdle`.
- Files: `fileOpen` (0 read, 1 readWrite, 2 append, 3 createTruncate), `fileClose`, `fileRead`, `fileWrite`, `fileSize`, `filePosition`, `fileSeek`, `fileFlush`, `fileDelete`, `fileRename`, `fileStat` (`{exists. isDir. size. mtimeµs}`), `dirEntries`, `dirCreate`, `cwd`, `mkfifo`, `spawnProcess` (argv Array, PATH lookup) → pid, `processWait` (pid block → status, or nil while running), `execProcess` (argv Array, PATH lookup: the VM's process runs it instead, same pid and standard streams, every other descriptor closed; fails if it cannot).
- Pseudo-terminals (`PlatformPtys`): `ptySpawn` (argv Array, PATH lookup; env Array of `NAME=value` or nil = the VM's; cwd or nil; rows cols) → `{pty. pid}`: forkpty, the child in its own session with default signal dispositions and no other fds, `TERM=xterm-256color` unless env sets it, `LC_CTYPE` of a UTF-8 locale (`C.UTF-8` on Linux, `UTF-8` on macOS: `PlatformHost utf8Ctype`) unless the locale (`LC_CTYPE`, else `LANG`) is UTF-8 already or `LC_ALL` is set, and `IUTF8` on the terminal (erase takes whole UTF-8 characters in cooked mode); `ptyRead` (0 once the child side closed, nil = would block), `ptyWrite` (nil = would block), `ptyResize` (rows cols: TIOCSWINSZ, the child gets SIGWINCH), `ptySemaphore` (pty readIdx [writeIdx], like `socketSemaphore`), `ptyWait` (pty block → exit status, or nil while running), `ptyClose` (hangs the child up with SIGHUP unless it ended; reaped later). Pty masters live in the socket table, so they are polled and signal like sockets.
- Sockets: `socketListen` (numeric address port backlog; port 0 picks a free one), `socketConnect` (numeric address port → socket at once, connecting), `socketConnected` (true once connected, nil while connecting: arms the write semaphore; fails with the OS error), `socketResolve` (host name → a socket that reads as its numeric addresses, a line each, or one line `!` and the resolver's error, then EOF: a detached thread runs `getaddrinfo` and writes to its end of a socket pair, touching nothing of the VM; closing the socket abandons the lookup), `socketAccept` (nil if none), `socketRecv` (0 at EOF, nil = would block), `socketSend` (nil = would block), `socketClose`, `socketSemaphore` (sock readIdx [writeIdx]), `socketLocalPort`.
- Raw network interface (`PlatformNic`): Ethernet frames for the image's TCP/IP stack (`NetworkStack`, System-Network) where the VM has no sockets of the OS: on UEFI the firmware's NIC (`UefiSnp`, docs/uefi.md); a host has none, and every one of these fails (`no raw network interface`). `nicOpen` (bytes, at least 6 → the same, the MAC address in the first 6; fails if there is no NIC), `nicSend` (bytes count → true, false if the transmit queue is full; a whole frame without its checksum), `nicReceive` (bytes → the length of the next frame received into them, nil if none: re-arms the semaphore), `nicSemaphore` (index: signaled once when a frame is waiting; 0 = none; while one is set the platform polls the NIC every ms), `nicStatus` (→ `{frames received. sent. sends that failed. frames waiting}`).
- TLS (`PlatformTLS`, OpenSSL 3): `tlsStart` (connected socket, host name → the same handle as a connection, without semaphores: SNI and the host the certificate must match), `tlsHandshake` (true once done, the certificate verified against the default trust store (`SSL_CTX_set_default_verify_paths`) and for host; nil while it waits: arms the semaphore OpenSSL waits for; a failed verification's reason is in `platformLastError`), `tlsRecv` (0 at EOF, nil = would block), `tlsSend` (nil = would block), `tlsClose`, `tlsSemaphore` (conn readIdx [writeIdx]). Connections live in the socket table, so they are polled like sockets; a handshake, read or write that would block arms the semaphore OpenSSL waits for, and a ready connection signals both its semaphores (a read may need to write, and a write to read). OpenSSL may hold decrypted bytes while the socket is not readable: read until nil before waiting.
- Machine (for drivers in Smalltalk, `Machine` in System-Devices; `PlatformMachine`, on UEFI `UefiMachine`): `machineSystemTable` (the firmware's system table; fails without a firmware: on every OS but UEFI), `machineCall` (fn, then up to 10 words: Integers, nil 0, Booleans 1 and 0 → the word the firmware function at the address fn answers, called in the firmware's convention, ms_abi on x86-64; fails without a firmware), `machineWatch` (event index: signal external semaphore index whenever the firmware signals the wait event at that address; the VM's wait wakes for it; 0 stops; fails without a firmware), `machineRead` (address size → the unsigned Integer of 1, 2, 4 or 8 bytes there), `machineWrite` (address size value), `machineCopy` (count src srcOffset dst dstOffset: addresses or byte objects/Bitmaps, 0-based offsets, overlap allowed), `machineAllocate` (size → the address of zeroed memory outside the object heap that never moves; on UEFI the firmware's pool, physical memory a device reads at that address), `machineFree`, `machineBarrier` (a full memory barrier). Addresses are Integers; misused, they crash the VM.
- Raster (the pixel work of a software GPU, `SoftwareRaster`; `PlatformRaster`, on every OS): `rasterDraw` (state vertices first count: the Renderer's 40-byte vertices at the address vertices drawn by its uber-shader, as `gpuDraw` on SDL_GPU draws them; state `{target. width. height. format. blend. scissorX. scissorY. scissorW. scissorH. viewportX. viewportY. viewportW. viewportH. viewSizeX. viewSizeY. translateX. translateY. texture (0: none). textureWidth. textureHeight. textureFormat. linear. repeat}`), `rasterFill` (address count bytesPerPixel value), `rasterBlit` (src {x. y. w. h} dst {x. y. w. h} linear, src and dst `{address. width. height. format}`: as `gpuBlit`), `rasterCopy` (dst dstStride src srcStride width height bytesPerPixel mode: rows of 1- or 4-byte pixels between addresses or byte objects; mode bit 1 swaps red and blue, bit 2 copies only pixels whose alpha is not 0).
- Formats: texture 1 r8, 2 rgba8, 3 bgra8. Texture usage bits: 1 sampler, 2 colorTarget. Buffer usage: 1 vertex. Shader stage: 0 vertex, 1 fragment. Blend: 0 none, 1 alpha, 2 premultiplied. Primitive type: 0 triangles, 1 strip, 2 lines, 3 lineStrip, 4 points. Vertex attributes `{fmt. offset. ...}`, where fmt is 1 float, 2 float2, 3 float3, 4 float4, 5 ubyte4norm, 6 ubyte4, 7 uint, 8 int. Attribute i becomes location i in vertex buffer slot 0.

**Events** `[type, timeMs, x, y, buttonOrKey, modifiers, textOrDelta, windowId]`. Coordinates are Float points. Modifiers: shift 1, ctrl 2, alt 4, cmd 8. Type codes: 1 mouseMove, 2 mouseDown, 3 mouseUp, 4 wheel (delta is a Point), 5 keyDown, 6 keyUp (SDL keycode; delta is the repeat flag), 7 textInput (String), 8 windowResized (x@y = new size), 9 windowCloseRequest, 10 quit, 11 focusGained, 12 focusLost, 13 displayScaleChanged (x = scale), 14 mouseLeave, 15 windowExposed, 16 textEditing (an input method's composition, a String; x its cursor and y the length of its selected part in characters, -1 if not set; SDL is told the image draws it, `SDL_HINT_IME_IMPLEMENTED_UI`). On Linux, where Alt is cmd, the text of a key typed with cmd is dropped; AltGr is SDL's mode modifier, not Alt, so its text is kept. mouseDown/Up carry the click count. Injecting with timeMs nil means "now".

**Semaphores.** Each semaphore is signaled once when something is pending, then stays quiet until re-armed. `nextEvent:`, `socketRecv`/`socketAccept` and `ptyRead` re-arm. A send that would block, or sends only part of the data, arms the write semaphore, as does a connect in progress. So drain until nil, then wait; a signal may be spurious.

**Nothing blocks the VM thread on the network.** A primitive completes at once or answers "would block" and arms a semaphore. `socketConnect` and `socketListen` take numeric addresses only (`AI_NUMERICHOST`), so no primitive reaches DNS; names are looked up by `socketResolve`'s thread. Waiting, timeouts, trying each address and cancelling are Smalltalk's: `RemoteSocket class>>connectTo:port:timeout:` (resolve, then connect to each address in turn), `TLSSocket class>>connectTo:port:timeout:` (then `tlsStart` and `tlsHandshake`), waiting on Semaphores; a whole connect answers or fails within its timeout (`connectTimeout`, 10 s), each address getting an equal share of the time left; terminating the waiting Process cancels.

**Uploads** are batched into one copy pass per device. The batch is submitted at the next `gpuSubmit`/`gpuDownload`, so it runs before that command buffer. Upload before recording the frame that uses the data. `gpuDownload` only sees work from command buffers that were submitted before it.

**GLSL on SDL_GPU/Vulkan (Linux).** `gpuCompileShader` (and `gpuCreateShader` given GLSL) compiles GLSL (`#version 450`) to SPIR-V with shaderc, whose glslang keeps about 70 MB of tables and pools for the life of a process that compiled once. `GPUShader` keeps the SPIR-V per source and stage in the image (stage 2 compiles the Renderer's), so an image starts without compiling; defining `SAMALTAK_VERTEX` or `SAMALTAK_FRAGMENT` for the stage, so one source can hold both stages under `#ifdef`; the entry point is `main` (GPUShader passes it whatever entry it was given). Bindings follow SDL_GPU's SPIR-V layout: vertex inputs are `layout(location = i) in`; vertex uniform slot n is `layout(set = 1, binding = n) uniform`; fragment sampled texture slot n is `layout(set = 2, binding = n) uniform sampler2D`, fragment uniform slot n `layout(set = 3, binding = n) uniform` (storage textures and buffers: sets 0 and 2, after the samplers). `gl_FragCoord` is MSL's `[[position]]` (pixel centers, origin top-left), `gl_VertexIndex` its `[[vertex_id]]`. Every built-in shader has a GLSL twin (`Renderer class>>glslShaderSource`, `FragmentShader class>>glslPrelude`, `ShaderView>>glslShaderSource`); a source is picked by `GPUDevice>>shaderLanguage`.

**MSL on SDL_GPU/Metal.** Entry points must not be named `main`; use names like `vmain`/`fmain`.
- Vertex shader: read inputs through `[[stage_in]]` with `[[attribute(i)]]`. Vertex buffer slot 0 is `[[buffer(14)]]` internally; don't write it by hand. Uniform slot n is `[[buffer(n)]]`.
- Fragment shader: sampled texture slot n is `[[texture(n)]]`, paired with `[[sampler(n)]]`. Uniform slot n is `[[buffer(n)]]`. Storage buffers come after the uniforms, storage textures after the sampled textures.
- Uniforms are pushed per command buffer with `gpuPushUniforms` and stay in effect for later draws. Pad structs to 16 bytes.
- NDC has y up; texture and framebuffer pixel origins are top-left.

**Present.** `gpuClaimWindow` picks MAILBOX, else IMMEDIATE, else VSYNC: the VM thread must never block on vsync. Metal offers VSYNC and IMMEDIATE, not MAILBOX, so on macOS it is IMMEDIATE; on Linux (Wayland, Mesa) MAILBOX. Even so, `nextDrawable` blocks when the app outruns the window server. On a 120 Hz ProMotion display, presenting on every vsync blocked each acquire for 4–9 ms. Presenting on every second `vsyncSemaphore` signal (60 Hz) kept acquires at about 0.03 ms. The compositor should present at ≤ 60 Hz, or skip frames when nothing changed. Swapchain textures are write-only, so render into an offscreen RGBA8 texture, blit it to the swapchain, and read back the offscreen one.

**Measured** on an M2 Max, 2880×1800 RGBA8 frame: upload 0.7 ms, render 0.5 ms, download 1.0 ms.

**VM hooks.** `SDLPlatform` defines `platform_interface_init`, `platform_interface_poll` (pumps SDL at most once per ms, polls sockets, signals semaphores), `platform_interface_wait(µs)` and `platform_interface_shutdown`. The GUI build links it instead of the core's `HeadlessPlatform` (both implement `PlatformInterface`). Since the VM only checks interrupts when something is due, the platform calls `request_periodic_poll(PF_POLL_US)` (1 ms) once video is initialized or a socket has a semaphore, so `platform_interface_poll` keeps pumping input and sockets while Smalltalk computes; while the VM idles, the wait itself returns on events. The wait blocks in `SDL_WaitEventTimeout`; a helper thread poll()s the armed sockets and the refresh thread wakes it (a CVDisplayLink on macOS; on Linux a thread sleeping to absolute deadlines at the primary display's refresh rate, as SDL offers no display link). Headless, it uses poll() alone. Link with `-lSDL3 -lssl -lcrypto -framework CoreVideo` on macOS (Homebrew's keg-only `openssl@3`, found with `brew --prefix` unless pkg-config knows it), `-lSDL3 -lssl -lcrypto -lshaderc_shared` on Linux. All calls run on the main thread.
